  issue: A permanent global HTTP latch changes credential behavior for unrelated later transports and is not established by every HTTP entry point.
  evidence:  sugra_api_mcp/server.py:407-413,459-461 and sugra_api_mcp/__main__.py:76-80: the permanent process-global HTTP flag is set only by the CLI branch; after HTTP is enabled, later stdio or in-process calls without request_ctx return the keyless client, while HTTP app factories that omit the CLI branch rely on request_ctx being present to avoid the env fallback.

- severity: S3
